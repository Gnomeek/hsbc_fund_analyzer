三种实现方案

选一个作为架构基础

A

纯 React + useMemo 手写

自己写过滤/排序逻辑，@base-ui/react 提供 Select/Checkbox 等 UI 原语。代码完全可控，无额外依赖。

缺点：列配置、多列排序、分页等逻辑需手写，约 200+ 行业务代码。

B ★

TanStack Table + @base-ui/react（推荐）

TanStack Table 处理排序/过滤/分页/列可见性全部逻辑（headless，无样式），@base-ui/react 负责 Select、Checkbox、Popover 等交互组件。两者都是 headless，完美互补。

优势：列配置、多列排序、全局搜索、行虚拟化都有现成 API，代码极简。

C

AG Grid Community + @base-ui/react

AG Grid 是最强大的表格库，内置虚拟滚动、Excel 导出、复杂过滤。

缺点：体积大（~400KB），样式定制成本高，对 598 行数据属于过度设计。
