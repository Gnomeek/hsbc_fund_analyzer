# HSBC CN Fund Analyzer

This repo extracts HSBC CN Funds data from [their site](https://fundsresearch.investments.hsbc.com.cn/rbwm/QuickRank.aspx), see also: [PDF](https://www.hsbc.com.cn/content/dam/hsbc/cn/docs/transfers/sales-agency-product-info-ut.pdf), extracting a CSV from the HTML file with Python script and build an interactive modern website based on that.
